# decisions — SwiftBar プラグイン化

- **2026-07-19 案A（フラグファイル + 状態ファイル）を採用**
  - 対案B: launchctl bootout 方式（watcher 無改造）→ 復帰ロジックが UI 側に
    二重化し「固定中」と「異常停止」を区別できないため却下
  - 対案C: SIGUSR1 シグナル方式 → 結局状態ファイルが必要で複雑さに見合わず却下
  - 理由: 状態の真実を watcher に一元化し UI を薄く保つ。ファイル IF は
    ロードマップ②（Swift ネイティブ化）へそのまま引き継げる

- **2026-07-19 オーバーライドは「高解像度固定」のみ・手動解除まで有効**
  - 低解像度側の固定は作らない（YAGNI）
  - 時間失効はしない。📌 アイコンで固定中が常時見えるため解除忘れは視認で防ぐ

- **2026-07-19 プラグインは symlink 設置、watcher は従来どおり cp 設置**
  - プラグインは UI のみで開発中の反映速度を優先
  - watcher は launchd が参照する実行物なので設置物を固定する

- **2026-07-19 state ファイルは key=value（zsh source 可能）形式**
  - JSON 等は zsh からのパースが面倒。source 一発で読める形式を優先
  - 書き込みは tmp + mv でアトミック、変化時のみ
