# requirements — SwiftBar プラグイン化

## 目的

watcher の現在状態（ホーム解像度 / 低解像度 / 固定中 / 停止）をメニューバーで
常時確認できるようにし、「高解像度に固定」の手動オーバーライドを追加する。
CLAUDE.md ロードマップ①に相当。

## 決定済み要件

- **オーバーライド操作**: 「高解像度に固定」と「自動に戻す」の 2 操作
  - 2026-07-19 実機確認後に追加: 「今すぐ低解像度にする」⇄「戻す」トグル。
    接続検知に依らず手動で上げ下げでき、検知不調時のフォールバック兼テスト手段
- **固定の寿命**: 手動解除までずっと有効。時間失効・切断時自動解除はしない
  （固定中はメニューバーの 📌 で常に視認できるため解除忘れに気づける）
- **メニュー内容**: 標準セット
  - 状態表示（現在モード・接続元 IP）
  - 固定 / 解除トグル
  - ログを開く
  - watcher を再起動
- **メニューバーアイコン**: 🏠=ホーム / 💻=低解像度 / 📌=固定中 / ⚠️=watcher 停止

## スコープ外

- ネイティブ Swift アプリ化（ロードマップ②。ただしファイル IF は②で再利用
  できる契約として設計する）
- IPv6 対応、複数ディスプレイ対応の変更
- watcher の判定・適用ロジック自体の変更

## 成功基準

1. リモート接続で 🏠→💻、切断で 💻→🏠 がメニューバーで追える
2. 📌 固定中はリモート接続してもホーム解像度のまま
3. 接続中に解除すると数秒（POLL_INTERVAL + SETTLE_DELAY）で低解像度になる
4. watcher を bootout すると ⚠️ になり、メニューから再起動できる
5. `make check` が全スクリプト（watcher / install.sh / プラグイン）を通る
