# requirements — 版表示とアプリ内アップデート

- **Date**: 2026-08-28
- **Base**: main @ 4503d8b (v1.0.1 公開済み)

## 要求

1. 現在のバージョンをアプリ内で確認できるようにする
2. アプリ内で更新の確認と適用ができるようにする (自動チェック / 手動チェックの両方)
3. README にインストール方法を示す

## スコープ

### やること

- メニューに現行版を表示する
- 起動後および 24 時間ごとの自動チェック、メニューからの手動チェック
- インストール元 (Homebrew cask / 直接) を判定し、経路ごとに違う導線を出す
  - Homebrew 経路: `brew upgrade --cask awayview` を提示するに留め、アプリは自分を置き換えない
  - 直接経路: ユーザーが明示的に押したときだけ、取得 → 署名検証 → 置換 → 再起動
- README (en/ja) のインストール手順を、現状の Homebrew で実際に通る形にする

### やらないこと (YAGNI)

- 無人での自動適用 (チェックは無人、適用は必ずユーザー操作)
- Sparkle 等の外部フレームワーク導入
- 差分更新・ロールバック・チャンネル (beta/stable) 分け
- 特定バージョンの skip 記憶
- `SMAppService` 登録パスの自己修復 (BACKLOG の別件)

## 受け入れ条件

- メニューを開くと現行版が読める
- 新版がある状態で、Homebrew 経路ではコマンドが提示され、アプリのバンドルが書き換わらない
- 新版がある状態で、直接経路では更新が適用され、再起動後に新版が常駐している
- 署名検証に失敗した成果物は適用されない
- LOW / lowManual / override 状態では更新を適用しない
- ネットワーク到達不能でも watcher は停止せず、ログに残って次回に回る
- `make test` が緑 (TZ・ロケール・ネットワーク非依存)
